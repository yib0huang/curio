# 隐私与数据处理

本文档描述当前本地 MVP 的数据行为，不构成已发布产品的正式隐私政策。

## 读取的数据

在用户打开 Side Panel 或刷新页面快照时，扩展可能读取当前普通网页的：

- 页面标题和 URL
- Meta 描述
- 可见正文文本，最多 50,000 个字符

Chrome 内部页面、Chrome Web Store 和其他受保护页面无法读取。

## 数据去向

- 页面快照、对话历史和流式返回的推理摘要暂存在 Side Panel 内存中。
- 只有用户点击复制按钮时，当前已提取的正文才会写入系统剪贴板。
- API 地址、模型名称和 API Key 保存在 `chrome.storage.local`。
- 只有用户发送问题时，页面快照、问题和最近 6 轮对话才会发送到配置的模型 API。
- 默认 OpenAI 请求设置 `store: false`；其他兼容 API 是否保留数据取决于对应服务商政策。
- 模型返回的 Markdown 不加载远程图片，避免展示回答时额外请求第三方资源。

## 当前不收集的数据

Curio 当前没有分析 SDK、自有服务器、广告系统或遥测，不会主动上传浏览历史，也不会读取密码输入框和表单内容作为页面正文。

## 发布前要求

正式发布前至少需要：

1. 用受控后端替代扩展内的服务端 API Key。
2. 提供用户可访问的正式隐私政策和数据删除说明。
3. 明确第三方模型服务商、数据保留规则和处理地域。
4. 审核 `<all_urls>` 权限是否可进一步缩小或改为按需授权。
5. 增加鉴权、限流、滥用防护和敏感信息过滤策略。
